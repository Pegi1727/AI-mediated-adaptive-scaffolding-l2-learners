# Reproducibility package

This site documents the repository for reproducing the achievement and questionnaire analyses of the supplied 50-student dataset.

## Contents

- `data/` — source and prepared datasets
- `python/` and `R/` — analysis pipelines
- `notebooks/` — interactive analysis notebooks
- `outputs/` and `figures/` — generated results

See the [repository README](README.md) for setup instructions and statistical notes.
